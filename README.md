# Task Manager MERN 🚧

> **⚠️ Project Under Construction**
>
> This project is currently under active development. New features and improvements are being added continuously.

A full-stack Task Management application built using the MERN stack. The application allows users to manage their tasks efficiently through a clean and responsive interface.

## 🚀 Current Features

* ✅ Add new tasks
* ✅ Store tasks in MongoDB Atlas
* ✅ REST API with Express.js
* ✅ React frontend with Axios integration
* ✅ Mongoose models and schemas

## 🛠 Tech Stack

### Frontend

* React
* Vite
* Axios
* CSS

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose
* dotenv
* cors

## 📌 Upcoming Features

* ⏳ View all tasks
* ⏳ Update tasks
* ⏳ Delete tasks
* ⏳ Mark tasks as completed
* ⏳ Task filtering and search
* ⏳ User authentication
* ⏳ Dark mode
* ⏳ Task priorities and categories

## ⚙️ Installation

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
